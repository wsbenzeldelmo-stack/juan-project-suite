# JUAN PROJECT Platform V1.3.3.2

Stability and startup hotfix. Workspace now opens in Offline / Local mode and connects to Supabase only when the admin explicitly chooses **Settings → Database Connection → Connect Database**. JUAN PROJECT Online renders onboarding/guest UI immediately instead of leaving a blank white screen while network requests run.

No new database migration is required beyond the migrations already used by V1.3.3.1.
