# JUAN PROJECT Platform V1.2 UX Standard

## Core principles
- Consistency and standards
- Clear visual hierarchy
- Error prevention before error reporting
- Visibility of system status
- Recognition over recall
- Progressive disclosure
- Fitts's Law for primary actions and touch targets
- Hick's Law through grouped navigation and reduced competing choices
- Jakob's Law through familiar admin and mobile-portal patterns
- Law of Proximity for related financial/project information
- Doherty Threshold through immediate loading/processing feedback
- Peak-End Rule through polished completion states

## Workspace hierarchy
Every primary page follows:

```text
Page label / context
Page title + primary action
Short description
Search / Sort / Filters
Main content
Loading / Empty / Error / Success feedback
```

## Online hierarchy
Online is not an admin dashboard. It is a guided client portal:

```text
Onboarding / Log In
Home
Orders → Order Tracker → Deliverables → Secure Project Folder
Payment
Shop
Account
```

## Status domains
Project: Pending / In Progress / Completed
Payment: Unpaid / Partially Paid / Paid / Overdue
Portal: Active / Needs Setup / Disabled
Delivery: Locked / Available / Expired / Delivered
