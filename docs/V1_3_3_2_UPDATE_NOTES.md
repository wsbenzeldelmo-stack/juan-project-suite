# JUAN PROJECT Platform V1.3.3.2

## Workspace
- Workspace opens immediately in Offline / Local mode.
- Supabase connection is manual from Settings → Database Connection.
- Manual controls: Load Deployed Config, Test Connection, Connect Database, Disconnect.
- Local/cached data remains visible without database/auth.
- Reports uses a compact, guarded renderer.
- Payment Reviews use the vertical action menu for Approve Request, Reject Request, and Delete Request; the large review modal is removed.

## JUAN PROJECT Online
- Immediate first paint; no long blank white wait for catalog/auth calls.
- First visit starts at the 3-slide onboarding.
- After onboarding the app enters Guest Mode.
- Protected features prompt the guest to log in; no public sign-up.
- Returning authenticated sessions load the client portal in the background.
- Portal-load errors offer Try Again, Browse as Guest, and Log Out.
- Only balance reminders are shown as dismissible popups.
- Invoice JUAN PROJECT logo viewBox widened so the final T is not clipped.
